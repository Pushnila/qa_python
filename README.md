# Проект: юнит-тестирование BooksCollector

В проекте реализованы тесты для класса `BooksCollector`.

## Запуск тестов

```bash
python -m pytest -v tests.py
```

## Реализованные проверки

1. Добавление двух книг в коллекцию.
2. Невозможность добавить книгу с названием длиннее 40 символов.
3. Установка допустимого жанра добавленной книге.
4. Получение `None` для книги, которой нет в коллекции.
5. Получение книг по определённому жанру.
6. Получение текущего словаря книг и жанров.
7. Исключение книг с возрастным рейтингом из списка книг для детей.
8. Добавление существующей книги в избранное.
9. Защита от повторного добавления книги в избранное.
10. Удаление книги из избранного.

Для проверок с разными наборами одинаковых входных данных используется параметризация pytest.
